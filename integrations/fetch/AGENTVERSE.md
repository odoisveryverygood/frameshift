# Sift — Verified 3D Performance Engineer

Run a real 3D optimization from ASI:One and receive the measured verdict and source patch without leaving the conversation.

1. Send `projects` to list the operator-authorized Three.js workloads.
2. Send `optimize PROJECT_ID: Make the moving robot fleet faster while preserving individual selection and appearance`.
3. Use the returned job ID: `status JOB_ID` until completed.
4. Send `evidence JOB_ID` for executed measurements and verification receipts.
5. Send `patch JOB_ID` for the actual accepted unified diff. If `nextOffset` is present, send `patch JOB_ID OFFSET` until complete. SHA-256 and total length identify the full patch.

The Investigator examines source/runtime evidence. Meta's Optimizer works on an isolated copy. SubQ plans regression checks; a deterministic Verifier executes them and controls acceptance. Fetch uAgents carry revision-bound specialist handoffs. This agent exposes these real local tools through the Agent Chat Protocol and mailbox.

Only an explicit operator allowlist is reachable. Arbitrary files, URLs, uploads, settings and Apply are unavailable. Failed and inconclusive experiments remain failures; they do not produce a verified patch. Only configured behavior is checked, on one local machine. CPU rendering submission time is not GPU utilization. This agent does not certify physical CAD repairs.

Public source and startup instructions: https://github.com/odoisveryverygood/frameshift/tree/feat/stl-repair-import/integrations/fetch

Keep the local Sift execution worker and this mailbox process running. The demo allowance is bounded; ask the operator if it is exhausted.
